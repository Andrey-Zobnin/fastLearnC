# Переменные и типы данных в языке C

## Хранение данных
- **Переменные** — изменяемые значения  
- **Константы / литералы** — неизменяемые значения  

Данные хранятся в ячейках памяти по 1 байту. В современных ОС каждая программа получает свою логическую область памяти.

## Объявление переменных
```c
char byte;          // тип + имя
byte = 100;         // присваивание
char a = byte;      // копирование значения
```
- Объявление **всегда** заканчивается точкой с запятой `;`
- Присваивание — **копирование** значения (переменные независимы)

## Правила имён переменных
- Только латинские буквы, цифры и `_`
- Нельзя начинать с цифры
- Чувствительны к регистру (`Name` ≠ `name`)
- Максимальная длина: 63 символа внутри модуля, 31 — вне
- Рекомендуется: маленькие буквы, существительные (`count`, `size`, `total`)

## Базовые типы данных

| Тип        | Размер (обычно) | Диапазон / назначение          |
|------------|-----------------|--------------------------------|
| `char`     | 1 байт          | символы / байт                 |
| `short`    | 2 байта         | целые числа                    |
| `int`      | 2 или 4 байта   | основной целочисленный тип     |
| `long`     | 4 или 8 байт    | длинные целые                  |
| `long long`| 8 байт          | очень большие целые (C99)      |
| `float`    | 4 байта         | вещественные                   |
| `double`   | 8 байт          | вещественные (предпочтительнее)|
| `long double` | ≥ 8 байт     | повышенная точность            |

> Размеры **не гарантированы** стандартом — зависят от платформы.

## Модификаторы `signed` / `unsigned`
- Применяются **только** к целочисленным типам
- `char` по умолчанию может быть как signed, так и unsigned (зависит от компилятора)
- Остальные целочисленные типы по умолчанию **signed**

```c
unsigned char fl_view;   // 0…255
signed char fl_view;     // -128…127
unsigned short d;        // беззнаковый short
```

## Рекомендации по выбору типа
- Символы / отдельные байты → `char`
- Целые числа → сначала `int`
- Много переменных + экономия памяти → `short` (если хватает диапазона)
- Большие числа → `long` / `long long`
- Дробные числа → `double` (реже `float`)
